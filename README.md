K-Means Clustering
A Machine Learning implementation of K-Means Clustering using Python and Scikit-learn to group data into clusters based on selected features.

Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Google Colab

Dataset
Country Dataset.

Workflow
1. Load the dataset
2. Prepare the data
3. Select relevant features
4. Apply K-Means Clustering
5. Determine the number of clusters
6. Train the clustering model
7. Visualize the clusters
8. Assign a new sample to a cluster

Clustering
K-Means Clustering groups countries based on similarities in their selected dataset features.

Purpose
This repository demonstrates K-Means Clustering for grouping data into meaningful clusters and applying the trained model to identify the cluster of a new sample.
